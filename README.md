# advent-of-code-2025
Solutions for Advent of Code 2025 - https://adventofcode.com/2025

## Setup

```bash
source .venv/bin/activate
```

## Formatting

```bash
python3 -m ruff format
```

## Run

```bash
python3 ./src/day1.py
python3 ./src/day2.py
```

## Unit tests

```bash
python3 -m pytest
```

## Linting

```bash
python3 -m ruff check --fix
```
